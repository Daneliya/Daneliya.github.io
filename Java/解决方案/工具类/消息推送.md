# 厂商推送

## 小米消息推送

开发文档

https://dev.mi.com/distribute/doc/details?pId=1558#\_13

将SDK打入到maven仓库

```PowerShell
mvn install:install-file -Dfile=文件路径\MiPush_SDK_Server_Http2_1.0.14.jar -DgroupId=com.tcmp.plugin -DartifactId=mipush -Dversion=1.0.14 -Dpackaging=jar -DgeneratePom=true
```

引入依赖

```XML
<!-- 小米推送 -->
<dependency>
    <groupId>com.tcmp.plugin</groupId>
    <artifactId>mipush</artifactId>
    <version>1.0.14</version>
</dependency>
<!-- 小米推送json解析包 -->
<dependency>
    <groupId>com.googlecode.json-simple</groupId>
    <artifactId>json-simple</artifactId>
    <version>1.1</version>
</dependency>
```

打包教程：https://blog.csdn.net/qq\_43412005/article/details/107863865

生成的JAR包

将JAR包打入到maven仓库

```PowerShell
# mvn install:install-file -Dfile=jar包的位置 -DgroupId=jar包的groupId -DartifactId=jar包的artifactId -Dversion=jar包的version -Dpackaging=jar

mvn install:install-file -Dfile=D:\huawei-push.jar -DgroupId=com.tcmp.plugin -DartifactId=huawei-push -Dversion=1.0 -Dpackaging=jar -DgeneratePom=true
```

引入依赖

```XML
<dependency>
    <groupId>com.tcmp.plugin</groupId>
    <artifactId>huawei-push</artifactId>
    <version>1.0</version>
</dependency>
```
