### 5、设置固定IP

默认情况下，设备的IP是被路由系统DHCP自动分配的，每次关机或重启后，路由器会重新给设备分配地址，这会造成我们每次重启后的IP不一样。会给我们的管理工作带来不便。为此我们需要固定设备的IP地址。

首先需要查看路由器的DHCPIP分配段，我们设备的IP需要设置到这个分配段之外，防止这个IP被DHCP自动分配给给它设备。

打开路由器的管理界面，点击路由设置，选择DHCP服务。

![image-20241020201151164](玩客云.assets/image-20241020201151164.png)

可以看到，路由器DHCP的地址池是在192.168.14.100-192.168.199之间进行分配。对设备设置的地址要在这个地址段之外，如我设置为192.168.14.99。

在ssh终端输入`ifconfig`，可以看到设备的MAC地址为：00:11:22:33:44:66。记住这个MAC地址，后面需要用上。

在ssh终端中，输入`vi /etc/network/interfaces.d/eth0`，对网卡的配置文件进行编辑。

```sh
auto eth0
iface eth0 inet dhcp
pre-up ifconfig eth0 hw ether 00:11:22:33:44:66
```

修改后

```sh
auto eth0
iface eth0 inet static #设置网卡地址为静态
address 192.168.0.99 #设置网卡的IP地址，需要在路由分配地址之外
network 192.168.0.0
netmask 255.255.255.0 #子网掩码
broadcast 192.168.0.255 #广播地址
gateway 192.168.0.1 #网关地址
dns-nameservers 192.168.0.1 #DNS地址
pre-up ifconfig eth0 hw ether 00:11:22:33:44:66 #MAC地址：前面在ifconfig中查询的结果
```

编辑完成后输入ESC和:wq保存退出。

```sh
sudo ifdown eth0 && sudo ifup eth0
```

### 7、问题

#### 终端连接问题

在 Mac 中使用 FinalShell 4.6.5 连接玩客云的时候，一直 connection is closed by foreign host，偶尔连上一次又断掉了。之前在使用 Win + MobaXterm 时没遇到过这种问题。

使用 DSH 分析

直接在 Mac 终端通过 `ssh root@192.168.0.99` 可以连接。按提示在 `系统设置 → 隐私与安全性 → 本地网络 → 找到 FinalShell` 也找不到 FinalShell。

确定几种原因

① 时钟慢了 25 天：System clock synchronized: no，RTC time: n/a。这台没硬件时钟，NTP 显示 active 但一直没同步成功。建议换个国内能通的 NTP 源（如 ntp.aliyun.com），timedatectl set-ntp true。这不会导致 SSH 掉线，但会让日志时间错乱、证书类服务出问题。

② FinalShell 是 ad-hoc 签名的 App，macOS 26 的「本地网络」权限不放行给这类应用，于是它连局域网的包根本发不出去——而且因为是静默拒绝，所以设置列表里也看不到它。公网 IP 不受此限制，所以你那三台云服务器一直正常。

基于以上问题修改

① Ubuntu 同步时间

第一步：修改 timesyncd 配置，换成阿里云 NTP

```
sudo vi /etc/systemd/timesyncd.conf
```

把里面内容替换成下面：

```
[Time]
NTP=ntp.aliyun.com ntp1.aliyun.com cn.ntp.org.cn
FallbackNTP=ntp.ubuntu.com
```

重启服务：

```
sudo systemctl restart systemd-timesyncd
```

第二步：查看同步状态

```
timedatectl timesync-status
```

等 10~30 秒，再执行

```
timedatectl
```

② 配置一个绕开限制的方案。原理：127.0.0.1（回环）不受本地网络权限管辖，所以在回环上开一个转发到 192.168.0.99:22，FinalShell 连回环即可。可以交由 DSH 开配置成开机自启的后台服务。

但是我不想增加开机自启服务。因此直接使用 Termius，下载地址：https://termius.com/download/macos

**问题2：青龙面板中更新的不是最新版本**

青龙面板中系统设置→其他设置→检查更新，只能拉到2.20.1，可是我看 GitHub 最新到2.24。

原因是本地 Docker 缓存坑，就算 hub 已经更新 latest，docker 本地有缓存的时候，`docker pull` 不会重新拉！

```
# 先清理本地缓存标记
docker system prune -a
```

或者在 Portainer 中删除镜像，重新 pull，然后重新安装。

#### 3.1.4、京东定时任务

参考 3.1.1 中的【Docker安装青龙面板及配置订阅+京东】文档

浏览器获取京东cookie教程：https://www.xujiahua.com/8405.html

浏览器插件获取京东cookie教程：https://www.xujiahua.com/8410.html

上面两种方式只要会其中一种即可。我们的目的是拿到 pt\_key=  和 pt\_pin= 这2个的值即可。

如果需获取第二个京东账号的 cookie，不要在刚才的浏览器上面退出登录账号一（否则刚才获取的cookie会失效），需另外换一个浏览器（Chrome浏览器 ctr+shift+n 打开无痕模式也行），然后继续按上面步骤操作即可

京东账号多开

为了让脚本跑起来，这里只要添加一个变量就可以：变量名`JD_COOKIE`，变量内容：

```sh
pt_key=A1;pt_pin=A2;&pt_key=B1;pt_pin=B2;&pt_key=C1;pt_pin=C2;
```

以上内容就是A、B、C三个京东账号的变量内容，如果有更多账号，按这个格式继续写下去即可。

A1，A2，…，C1, C2 替换为获取到的值！

这里只挂了三个京东账号，如果要挂更多账号，只要编辑变量JD\_COOKIE的内容继续以&符号分割往后加cookie就可以了！

到这里就设置好了，可以挂上京东账号跑了。

### 3.2、DDNSTO内网穿透

**什么是 DDNSTO？**

DDNSTO 是一款内网穿透工具，让你在外网也能访问家里的设备：

* 📱 手机远程查看 NAS 照片、视频
* 💻 公司访问家里的路由器管理界面
* 🎬 外出时远程控制下载任务
* 🖥️ 远程连接家里电脑桌面

**核心优势：**

* ✅ 无需公网 IP
* ✅ 无需购买域名和服务器
* ✅ 全部操作在浏览器完成，无需敲代码
* ✅ 支持 HTTPS，访问更安全

DDNSTO官网：https://web.ddnsto.com

官方文档：https://doc.linkease.com/zh/guide/ddnsto/start.html

DDNSTO配置教程：https://post.smzdm.com/p/a3dd9qwn
