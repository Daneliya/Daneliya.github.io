# 强化学习与对齐面试题详解

## 一、强化学习与对齐概述

强化学习与对齐是大模型训练的关键阶段，通过人类反馈使模型行为符合人类偏好，提高模型的有用性、安全性和诚实性。

### 核心目标

| 目标 | 说明 |
|------|------|
| **有用性（Helpful）** | 提供有价值的信息和帮助 |
| **安全性（Harmless）** | 避免生成有害内容 |
| **诚实性（Honest）** | 不编造信息，承认不确定性 |

## 二、面试题列表

### 2.1 PPO vs DPO vs GRPO

**面试题**：请详细说明PPO、DPO和GRPO三种优化算法的核心思想、适用场景及主要区别

**考察点**：算法对比

**详细解答**：

| 对比维度 | PPO（近端策略优化） | DPO（直接偏好优化） | GRPO（广义无奖励策略优化） |
|----------|---------------------|---------------------|---------------------------|
| **核心模型数量** | 4个(Actor, Critic, RM, Ref) | 2个(策略模型, 参考模型) | 2个或1个 |
| **是否需要 RM** | 是 | 否 | 否 |
| **是否需要 Critic** | 是 | 否 | 否 |
| **核心思想** | 裁剪目标函数限制更新幅度 | 跳过 RM，直接用偏好数据优化策略 | 组内相对奖励估计优势 |
| **训练稳定性** | 稳定但需精细调参 | 好 | 依赖奖励规则质量 |
| **适用场景** | 通用复杂对齐任务 | 快速迭代、简单偏好 | 数学/代码等可验证任务 |
| **代表模型** | ChatGPT(InstructGPT) | Llama 系列对齐 | DeepSeek-R1 |

**PPO 原理**：

```python
# PPO 目标函数
def ppo_loss(advantage, ratio, clip_epsilon):
    # ratio = π_new / π_old
    clipped_ratio = torch.clamp(ratio, 1 - clip_epsilon, 1 + clip_epsilon)
    loss = torch.min(ratio * advantage, clipped_ratio * advantage)
    return -loss.mean()
```

**DPO 原理**：

```python
# DPO 损失函数
def dpo_loss(policy_chosen, policy_rejected, ref_chosen, ref_rejected, beta):
    # 计算 log 概率比
    log_ratio_chosen = policy_chosen - ref_chosen
    log_ratio_rejected = policy_rejected - ref_rejected
    
    # DPO 损失
    loss = -F.logsigmoid(beta * (log_ratio_chosen - log_ratio_rejected))
    return loss.mean()
```

**GRPO 原理**：

```python
# GRPO 使用组内相对奖励
def grpo_loss(rewards, log_probs, ref_log_probs, beta):
    # 组内相对奖励
    advantages = (rewards - rewards.mean()) / (rewards.std() + 1e-8)
    
    # 策略梯度损失
    ratio = torch.exp(log_probs - ref_log_probs)
    clipped_ratio = torch.clamp(ratio, 0.8, 1.2)
    loss = -torch.min(ratio * advantages, clipped_ratio * advantages)
    return loss.mean()
```

**选型建议**：

* 通用聊天对齐 → PPO 或 DPO
* 数学/代码推理 → GRPO
* 快速原型 → DPO
* 工业界常用两阶段：DPO 快速对齐 + PPO 精细调优

### 2.2 DPO vs PPO 深度对比

**面试题**：请比较DPO与PPO在大模型对齐中的应用，从算法原理、实现复杂度、训练稳定性和效果表现等方面进行分析

**考察点**：对齐方法

**详细解答**：

**核心区别**：优化范式根本不同

* **PPO**：在线强化学习，三模型架构，"探索→反馈→更新"循环
* **DPO**：离线监督学习，单模型架构，将 RL 问题转化为分类问题

| 维度 | PPO | DPO |
|------|-----|-----|
| **算法原理** | 在线 RL，与 RM 交互优化策略 | 离线分类，直接最大化 chosen/rejected 似然比 |
| **实现复杂度** | 高，需维护多个模型 | 低，几行代码即可实现 |
| **训练稳定性** | 差，易出现 reward hacking 和模式崩溃 | 好，凸优化问题 |
| **效果上限** | 高，在线探索能力强 | 中，对分布外数据敏感 |
| **数据需求** | 中等（需 RM 打分） | 需成对偏好数据 |

**PPO 训练流程**：

```python
# PPO 训练循环
for epoch in range(num_epochs):
    # 1. 采样
    responses = actor.generate(prompts)
    
    # 2. RM 打分
    rewards = reward_model.score(prompts, responses)
    
    # 3. 计算优势
    values = critic.value(prompts, responses)
    advantages = compute_advantages(rewards, values)
    
    # 4. PPO 更新
    for _ in range(ppo_epochs):
        ratio = new_prob / old_prob
        loss = ppo_loss(advantages, ratio)
        actor.update(loss)
        critic.update(values, rewards)
```

**DPO 训练流程**：

```python
# DPO 训练
for batch in dataloader:
    chosen_responses = policy(batch.chosen_prompts)
    rejected_responses = policy(batch.rejected_prompts)
    
    with torch.no_grad():
        ref_chosen = ref_model(batch.chosen_prompts)
        ref_rejected = ref_model(batch.rejected_prompts)
    
    loss = dpo_loss(chosen_responses, rejected_responses,
                    ref_chosen, ref_rejected, beta)
    loss.backward()
    optimizer.step()
```

**DPO 局限**：

1. 效果依赖 BT 模型假设
2. 分布外泛化弱
3. 长文本生成信号衰减严重

**PPO 不可替代场景**：

1. 强探索任务（数学推理/代码生成）
2. 长文本生成
3. 多轮交互

### 2.3 Reward 函数设计

**面试题**：在RLHF中，设计Reward函数时应综合考虑哪些关键因素？

**考察点**：Reward 设计

**详细解答**：

**Reward 函数设计原则**：

**1. 多维度评估**

```python
def reward_function(response, prompt):
    helpfulness = evaluate_helpfulness(response, prompt)
    safety = evaluate_safety(response)
    honesty = evaluate_honesty(response)
    
    # 加权组合
    reward = (0.5 * helpfulness + 
              0.3 * safety + 
              0.2 * honesty)
    return reward
```

**2. 有用性评估**

* 回答是否解决了用户问题
* 信息是否准确、完整
* 是否易于理解

**3. 安全性评估**

* 是否包含有害内容
* 是否有偏见或歧视
* 是否泄露隐私信息

**4. 诚实性评估**

* 是否承认不确定性
* 是否编造信息
* 是否提供来源

**Reward 函数示例**：

```python
class RewardModel:
    def __init__(self):
        self.safety_classifier = SafetyClassifier()
        self.fact_checker = FactChecker()
    
    def score(self, prompt, response):
        # 1. 相关性得分
        relevance = self.compute_relevance(prompt, response)
        
        # 2. 安全性得分
        safety = self.safety_classifier.score(response)
        
        # 3. 事实性得分
        factuality = self.fact_checker.check(response)
        
        # 4. 流畅性得分
        fluency = self.compute_fluency(response)
        
        # 综合得分
        score = (0.4 * relevance + 
                 0.3 * safety + 
                 0.2 * factuality + 
                 0.1 * fluency)
        
        return score
```

### 2.4 长周期任务建模

**面试题**：在强化学习或Agent系统中，如何对长周期（long-horizon）任务进行建模和训练？

**考察点**：长周期任务

**详细解答**：

**长周期任务的挑战**：

1. 奖励稀疏：只有任务完成才有奖励
2. 信用分配：难以确定哪些动作导致成功
3. 探索困难：状态空间大，难以有效探索

**解决方案**：

**1. 分层强化学习**

```python
# 高层策略：选择子任务
class HighLevelPolicy:
    def select_subtask(self, state):
        # 将长周期任务分解为子任务
        subtask = self.policy(state)
        return subtask

# 低层策略：执行子任务
class LowLevelPolicy:
    def execute_subtask(self, state, subtask):
        # 执行具体动作
        action = self.policy(state, subtask)
        return action
```

**2. 奖励塑形**

````python
# 添加中间奖励
def shaped_reward(state, action, next_state, goal):
    # 原始奖励
    env_reward = environment_reward(next_state, goal)
    
    # 启发式奖励
    heuristic_reward = distance_heuristic(next_state, goal)
    
    # 组合奖励
    return env_reward + 0.1 * heuristic_reward
``**

**3. 经验回放**
```python
# 优先经验回放
class PrioritizedReplayBuffer:
    def __init__(self):
        self.buffer = []
        self.priorities = []
    
    def add(self, experience, priority):
        self.buffer.append(experience)
        self.priorities.append(priority)
    
    def sample(self, batch_size):
        # 根据优先级采样
        probs = np.array(self.priorities) / sum(self.priorities)
        indices = np.random.choice(len(self.buffer), batch_size, p=probs)
        return [self.buffer[i] for i in indices]
````

**4. 课程学习**

```python

curriculum = [
    {"task": "simple", "episodes": 1000},
    {"task": "medium", "episodes": 2000},
```

### 2.5 稀疏奖励与信用分配

**面试题**：在处理长视野任务时，智能体常面临稀疏奖励和信用分配难题，请说明关键技术手段

**考察点**：稀疏奖励

**详细解答**：

**稀疏奖励问题**：

* 只有任务完成才有奖励
* 中间状态没有反馈
* 难以学习有效策略

**信用分配问题**：

* 不知道哪些动作导致成功
* 难以区分好动作和坏动作
* 学习效率低

**解决方案**：

**1. 时序差分学习（TD Learning）**

```python
# TD(0) 更新
def td_update(V, state, next_state, reward, gamma, alpha):
    td_target = reward + gamma * V[next_state]
    td_error = td_target - V[state]
    V[state] += alpha * td_error
    return td_error
```

**2. 优势函数估计**

```python
# GAE（广义优势估计）
def compute_advantages(rewards, values, gamma, lambda_):
    advantages = []
    gae = 0
    
    for t in reversed(range(len(rewards))):
        delta = rewards[t] + gamma * values[t + 1] - values[t]
        gae = delta + gamma * lambda_ * gae
        advantages.insert(0, gae)
    
    return advantages
```

**3. 奖励塑形**

```python
# 势函数奖励塑形
def potential_based_shaping(state, next_state, gamma):
    # 势函数
    phi_s = potential_function(state)
    phi_ns = potential_function(next_state)
    
    # 塑形奖励
    return gamma * phi_ns - phi_s
```

**4. Hindsight Experience Replay（HER）**

```python
# 将失败经验转化为成功经验
def hindsight_replay(episode, achieved_goal):
    for transition in episode:
        # 替换目标为实际达到的目标
        new_transition = transition.copy()
        new_transition.goal = achieved_goal
        new_transition.reward = compute_reward(achieved_goal, achieved_goal)
        replay_buffer.add(new_transition)
```

**5. 内在奖励**

```python
# 好奇心驱动探索
def intrinsic_reward(state, next_state, action):
    # 预测误差作为好奇心
    predicted_next = forward_model(state, action)
    curiosity = mse(predicted_next, next_state)
    return curiosity
```
