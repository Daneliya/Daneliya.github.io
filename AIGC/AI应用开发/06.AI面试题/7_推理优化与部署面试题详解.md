# 推理优化与部署面试题详解

## 一、推理优化与部署概述

推理优化与部署是大模型工程化的核心环节，涉及模型压缩、加速推理、服务部署等技术，直接影响模型的实际应用效果和成本。

### 核心挑战

| 挑战 | 说明 |
|------|------|
| **延迟** | 用户等待时间 |
| **吞吐量** | 单位时间处理请求数 |
| **成本** | GPU 资源和运营成本 |
| **显存** | 模型和 KV Cache 占用 |

## 二、面试题列表

### 2.1 大模型优化方法全景

**面试题**：在大模型应用中，常见的模型优化方法有哪些？请从训练、推理和部署角度阐述

**考察点**：全局优化

**详细解答**：

**三大阶段优化策略**：

#### 训练阶段

| 优化方向 | 方法 | 效果 |
|----------|------|------|
| **并行策略** | 数据并行(DDP/FSDP)、模型并行(Tensor/Pipeline)、ZeRO 优化 | 突破单卡显存限制 |
| **计算效率** | 混合精度(FP16/BF16，提速 2-3 倍)、梯度检查点(节省 40-60% 显存)、Flash Attention(提速 2-4 倍) | 显著提升训练速度 |

**并行策略详解**：

```python
# 数据并行
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

model = DDP(model, device_ids=[local_rank])

# 模型并行（Tensor Parallel）
class TensorParallelLinear(nn.Module):
    def __init__(self, in_features, out_features, world_size):
        super().__init__()
        # 将权重分片到不同 GPU
        self.weight = nn.Parameter(
            torch.empty(out_features // world_size, in_features)
        )

# ZeRO 优化
from deepspeed import initialize

model, optimizer, _, _ = initialize(
    model=model,
    config="ds_config.json"  # 包含 ZeRO 配置
)
```

#### 推理阶段

| 优化方向 | 方法 | 效果 |
|----------|------|------|
| **内存优化** | KV Cache + PageAttention + MQA/GQA | 降低长文本显存占用 |
| **计算优化** | Continuous Batching | 提升 GPU 利用率 |
| **解码优化** | 投机解码(Speculative Decoding，提速 2-3 倍)、并行化 Top-K/Top-P | 降低延迟 |

**KV Cache 优化**：

```python
# KV Cache 基本原理
class KVCache:
    def __init__(self, max_seq_len, num_layers, num_heads, head_dim):
        self.cache = torch.zeros(
            num_layers, 2, max_seq_len, num_heads, head_dim
        )
    
    def update(self, layer, position, key, value):
        self.cache[layer, 0, position] = key
        self.cache[layer, 1, position] = value
    
    def get(self, layer, seq_len):
        return self.cache[layer, :, :seq_len]
```

**Continuous Batching**：

```python
# 动态批处理
class ContinuousBatcher:
    def __init__(self, max_batch_size):
        self.max_batch_size = max_batch_size
        self.active_requests = []
    
    def add_request(self, request):
        if len(self.active_requests) < self.max_batch_size:
            self.active_requests.append(request)
    
    def step(self):
        # 处理所有活跃请求
        # 完成的请求移除，新请求加入
        completed = []
        for req in self.active_requests:
            if req.is_done():
                completed.append(req)
        
        for req in completed:
            self.active_requests.remove(req)
```

#### 部署阶段

| 优化方向 | 方法 | 精度损失 |
|----------|------|----------|
| **量化** | INT8(SmoothQuant) | <1% |
| **量化** | INT4(GPTQ/AWQ) | 2-5% |
| **蒸馏** | 模型蒸馏 | 可控 |
| **服务层** | 模型切分部署(PP+TP)、请求调度(优先级队列/抢占式) | - |

**量化示例**：

```python
# INT8 量化
from torch.quantization import quantize_dynamic

quantized_model = quantize_dynamic(
    model,
    {nn.Linear},
    dtype=torch.qint8
)

# GPTQ 量化
from auto_gptq import AutoGPTQForCausalLM

model = AutoGPTQForCausalLM.from_pretrained(
    model_path,
    quantize_config={
        "bits": 4,
        "group_size": 128,
        "damp_percent": 0.01
    }
)
```

**系统性优化思维**：「全栈分析 → 定位瓶颈 → 针对性优化」

* 瓶颈在通信与计算？→ 优化并行策略
* 瓶颈是内存带宽？→ 量化 + KV Cache 优化
* 瓶颈是请求波动？→ 弹性扩缩容 + Continuous Batching

### 2.2 推理框架对比

**面试题**：请列举并比较主流的大语言模型推理框架（vLLM、TensorRT-LLM、HuggingFace TGI、llama.cpp等）

**考察点**：推理框架

**详细解答**：

| 维度 | vLLM | TensorRT-LLM | HuggingFace TGI | llama.cpp |
|------|------|---------------|-----------------|-----------|
| **核心创新** | PagedAttention | 算子融合+TensorRT | 开箱即用 HuggingFace 生态 | CPU/GPU 混合+极致量化 |
| **吞吐量** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ |
| **延迟(P99)** | 低 | 极低 | 中等 | 高 |
| **易用性** | 好 | 较差（需编译转换） | 最好 | 好 |
| **模型支持** | 广(HF 生态) | 需转 ONNX/TensorRT | 广(HF Hub) | Llama 系列等 |

**各框架详解**：

#### vLLM

```python
# vLLM 使用示例
from vllm import LLM, SamplingParams

llm = LLM(model="meta-llama/Llama-2-7b-chat-hf")
sampling_params = SamplingParams(temperature=0.8, top_p=0.95)

outputs = llm.generate(["Hello, my name is"], sampling_params)
print(outputs[0].outputs[0].text)
```

**核心特性**：

* PagedAttention：高效管理 KV Cache
* Continuous Batching：动态批处理
* Tensor Parallel：多 GPU 支持

#### TensorRT-LLM

```python
# TensorRT-LLM 构建
import tensorrt_llm

# 构建引擎
builder = tensorrt_llm.Builder()
network = builder.create_network()
# ... 定义模型结构
engine = builder.build_engine(network, config)
```

**核心特性**：

* 算子融合：减少 kernel 启动开销
* 量化支持：INT8/INT4 量化
* 极致优化：针对 NVIDIA GPU 深度优化

#### HuggingFace TGI

```bash
# TGI 部署
docker run --gpus all -p 8080:80 \
    -v ./data:/data \
    ghcr.io/huggingface/text-generation-inference:latest \
    --model-id meta-llama/Llama-2-7b-chat-hf
```

**核心特性**：

* 开箱即用：简单部署
* HuggingFace 生态：无缝集成
* 流式输出：支持 SSE

#### llama.cpp

```bash
# llama.cpp 使用
./main -m ./models/llama-7b.ggmlv3.q4_0.bin \
       -p "Hello my name is" \
       -n 128 \
       --temp 0.8
```

**核心特性**：

* CPU 支持：可在 CPU 上运行
* 极致量化：2-8 bit 量化
* 轻量级：资源占用少

**选型建议**：

* 高吞吐在线服务 → vLLM
* 极致延迟要求(P99<50ms) → TensorRT-LLM
* 快速验证/多模型切换 → HuggingFace TGI
* 边缘设备/CPU 部署 → llama.cpp

### 2.3 问题排查与优化

**面试题**：当一个大模型在特定任务或任务类别上表现不佳时，有哪些系统性的排查和优化策略？

**考察点**：问题排查

**详细解答**：

**系统性排查流程**：

```
问题定位 → 数据分析 → 模型评估 → 优化策略 → 验证效果
```

**1. 问题定位**

```python
# 分析错误模式
def analyze_errors(predictions, references, inputs):
    errors = []
    for pred, ref, inp in zip(predictions, references, inputs):
        if not match(pred, ref):
            errors.append({
                "input": inp,
                "prediction": pred,
                "reference": ref,
                "error_type": classify_error(pred, ref)
            })
    
    # 统计错误类型
    error_types = Counter([e["error_type"] for e in errors])
    return error_types
```

**2. 数据分析**

```python
# 检查数据质量
def check_data_quality(dataset):
    issues = []
    
    # 检查标签分布
    label_dist = Counter([d["label"] for d in dataset])
    if max(label_dist.values()) / len(dataset) > 0.9:
        issues.append("标签不平衡")
    
    # 检查数据质量
    for d in dataset:
        if len(d["text"]) < 10:
            issues.append(f"过短样本: {d['text']}")
        if has_noise(d["text"]):
            issues.append(f"噪声数据: {d['text'][:50]}")
    
    return issues
```

**3. 模型评估**

```python
# 多维度评估
def evaluate_model(model, test_set):
    metrics = {}
    
    # 整体性能
    metrics["overall"] = compute_metrics(model, test_set)
    
    # 分类别性能
    for category in test_set.categories:
        subset = test_set.filter(category=category)
        metrics[category] = compute_metrics(model, subset)
    
    # 难度分析
    for difficulty in ["easy", "medium", "hard"]:
        subset = test_set.filter(difficulty=difficulty)
        metrics[difficulty] = compute_metrics(model, subset)
    
    return metrics
```

**4. 优化策略**

**数据层面**：

* 增加相关领域数据
* 数据清洗和增强
* 调整数据配比

**模型层面**：

* 领域微调
* 增加模型容量
* 调整模型结构

**训练层面**：

* 调整学习率
* 增加训练轮数
* 使用课程学习

**推理层面**：

* 调整解码参数
* 使用 RAG 增强
* 后处理优化

**5. 验证效果**
