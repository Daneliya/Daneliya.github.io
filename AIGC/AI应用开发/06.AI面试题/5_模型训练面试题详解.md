# 模型训练面试题详解

## 一、模型训练概述

模型训练是大模型开发的核心环节，包括预训练、微调、对齐等阶段。理解训练过程中的关键技术对于优化模型性能至关重要。

| **预训练** | 大规模无监督学习，学习通用知识 |

| **对齐（RLHF）** | 人类反馈强化学习，对齐人类偏好 |

### 2.1 DDPM vs Flow Matching

**面试题**：请比较DDPM与Flow Matching在建模思路、训练目标、采样效率和理论基础方面的核心区别

**考察点**：生成模型对比

**详细解答**：

| 维度 | DDPM（去噪扩散概率模型） | Flow Matching |
|------|---------------------------|---------------|
| **建模思路** | 逐步加噪→逐步去噪 | 学习从噪声到数据的连续流 |
| **训练目标** | 预测噪声 | 预测速度场/流场 |
| **采样效率** | 慢，需要多步去噪 | 快，可减少采样步数 |
| **理论基础** | 随机微分方程(SDE) | 常微分方程(ODE) |

**DDPM 原理**：

```python
# 前向过程：逐步加噪
def forward_diffusion(x0, t, noise):
    alpha_t = alpha_schedule[t]
    return sqrt(alpha_t) * x0 + sqrt(1 - alpha_t) * noise

# 反向过程：逐步去噪
def reverse_diffusion(xt, t, model):
    predicted_noise = model(xt, t)
    # 根据预测的噪声计算 x_{t-1}
    return denoise_step(xt, predicted_noise, t)
```

**Flow Matching 原理**：

```python
# 学习从噪声到数据的连续流
def flow_matching_loss(x0, noise, t):
    # 插值
    xt = (1 - t) * noise + t * x0
    # 目标速度场
    target_velocity = x0 - noise
    # 预测速度场
    predicted_velocity = model(xt, t)
    # 损失
    return mse(predicted_velocity, target_velocity)
```

**核心区别**：

1. **建模思路**
   * DDPM：将生成过程建模为马尔可夫链，逐步去噪
   * Flow Matching：学习从噪声分布到数据分布的连续变换

2. **训练目标**
   * DDPM：预测每一步的噪声
   * Flow Matching：预测速度场（变换的导数）

3. **采样效率**
   * DDPM：通常需要数百步去噪
   * Flow Matching：可通过 ODE 求解器减少步数

4. **理论基础**
   * DDPM：基于随机微分方程(SDE)
   * Flow Matching：基于常微分方程(ODE)

### 2.2 DDPM 训练策略

**面试题**：在DDPM的训练过程中，为何采用随机选择时间步进行加噪并学习对应去噪的方式？

**考察点**：训练策略

**详细解答**：

**随机选择时间步的原因**：

1. **覆盖所有噪声水平**
   * 模型需要学习从任意噪声水平恢复
   * 随机采样确保覆盖整个噪声范围

2. **训练效率**
   * 每次只需计算一个时间步的损失
   * 而非遍历所有时间步

3. **重要性采样**
   * 不同时间步的难度不同
   * 随机采样是一种简单的重要性采样

**训练流程**：

```python
def train_step(model, x0):
    # 随机选择时间步
    t = torch.randint(0, T, (batch_size,))
    
    # 随机采样噪声
    noise = torch.randn_like(x0)
    
    # 加噪
    xt = forward_diffusion(x0, t, noise)
    
    # 预测噪声
    predicted_noise = model(xt, t)
    
    # 计算损失
    loss = mse(predicted_noise, noise)
    
    return loss
```

**时间步采样策略**：

1. **均匀采样**：每个时间步等概率
2. **重要性采样**：根据损失大小调整概率
3. **余弦调度**：关注中间时间步

### 2.3 SFT 后概率分布变化

**面试题**：在进行监督微调（SFT）后，某些分类模型的预测概率分布从原本较为集中变为更加均匀，请分析原因

**考察点**：SFT 现象

**详细解答**：

**现象描述**：

* 预训练模型：预测概率分布集中（高置信度）
* SFT 后：预测概率分布均匀（低置信度）

**可能原因**：

**1. 过拟合**

```python
# SFT 数据量小，模型过拟合
# 训练集上损失低，但泛化能力差
# 导致在测试集上置信度下降
```

**2. 标签噪声**

```python
# SFT 数据中存在错误标签
# 模型学习到噪声，降低置信度
```

**3. 分布偏移**

```python
# SFT 数据分布与预训练数据不同
# 模型在新分布上不确定
```

**4. 正则化不足**

```python
# SFT 过程中正则化不足
# 模型过度适应训练数据
```

**解决方案**：

1. **增加数据量**：收集更多高质量数据
2. **数据清洗**：去除错误标签
3. **正则化**：添加 dropout、weight decay
4. **温度校准**：调整 softmax 温度

### 2.4 PyTorch 动态计算图

**面试题**：请解释PyTorch中动态计算图的工作机制，包括自动微分的实现原理

**考察点**：框架原理

**详细解答**：

**核心机制**：

**1. Define-by-Run**

* 每次前向传播构建新计算图
* 图结构随输入动态变化
* 支持条件分支、循环等动态结构

**2. 自动微分**

* 反向传播时沿计算图自动计算梯度
* 使用链式法则

**动态计算图示例**：

```python
import torch

# 动态计算图
x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)

# 前向传播构建计算图
if x.sum() > 5:
    y = x ** 2
else:
    y = x ** 3

# 反向传播计算梯度
y.backward(torch.ones_like(x))
print(x.grad)  # 自动计算梯度
```

**自动微分原理**：

```python
# 每个操作记录在计算图中
class Function:
    def __init__(self, *inputs):
        self.inputs = inputs
        self.outputs = None
    
    def forward(self):
        raise NotImplementedError
    
    def backward(self, grad_output):
        raise NotImplementedError

# 链式法则
def backward(grad_output):
    for input in self.inputs:
        if input.requires_grad:
            input.grad += self.local_grad(grad_output)
            input.backward(input.grad)
```

**动态 vs 静态计算图**：

| 维度 | 动态计算图（PyTorch） | 静态计算图（TensorFlow 1.x） |
|------|----------------------|------------------------------|
| **构建时机** | 运行时构建 | 预先定义 |
| **灵活性** | 高，支持动态控制流 | 低，需要特殊操作 |
| **调试** | 容易，可使用标准调试器 | 困难 |
| **优化** | 较难优化 | 可以全局优化 |
| **部署** | 需要导出 | 直接部署 |

**PyTorch 的优势**：

1. **直观易用**：像普通 Python 代码一样编写
2. **易于调试**：可以使用标准 Python 调试工具
3. **灵活**：支持动态控制流
