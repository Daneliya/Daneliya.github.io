CodeBuddy ​

一、CodeBuddy 简介 ​

CodeBuddy 是腾讯云推出的 AI 代码助手，支持多种 AI 模型接入，帮助开发者提高编码效率。它提供 IDE 插件和命令行工具两种使用方式。

1.1 核心特性 ​

特性说明
多模型支持支持接入 OpenAI、DeepSeek、小米 MiMo 等多种模型
代码生成根据自然语言描述生成代码
代码补全智能代码补全建议
代码解释解释复杂代码逻辑
代码重构智能优化和重构代码
多平台支持支持 VS Code、JetBrains IDE、命令行

1.2 使用方式 ​

  • CodeBuddy IDE：独立的 IDE 应用
  • VS Code 插件：通过扩展市场安装
  • CLI 命令行：通过 npm 安装命令行工具

二、安装配置 ​

2.1 前置要求 ​

  • Node.js 18.20 或更高版本（CLI 方式需要）
  • 有效的 API 密钥

2.2 安装方式 ​

方式一：CodeBuddy IDE ​

  1. 访问 CodeBuddy 官网
  2. 下载对应系统的安装包
  3. 安装并启动

方式二：VS Code 插件 ​

  1. 打开 VS Code
  2. 进入扩展市场
  3. 搜索 "Tencent Cloud CodeBuddy"
  4. 安装插件

方式三：CLI 命令行 ​

bash
# 全局安装
npm install -g @tencent-ai/codebuddy-code

# 验证安装
codebuddy --version

三、模型配置 ​

CodeBuddy 支持通过 models.json 配置文件自定义模型列表。

3.1 配置文件位置 ​

系统路径
Windows用户目录\.codebuddy\models.json
macOS~/.codebuddy/models.json
项目级<项目根目录>/.codebuddy/models.json

配置优先级（从高到低）：

  1. 项目级 models.json
  2. 用户级 models.json
  3. 内置默认配置

3.2 配置文件结构 ​

json
{
  "models": [
    {
      "id": "model-id",
      "name": "显示名称",
      "vendor": "供应商",
      "apiKey": "API密钥",
      "url": "API端点/chat/completions",
      "supportsToolCall": true,
      "supportsImages": false
    }
  ],
  "availableModels": ["model-id-1", "model-id-2"]
}

3.3 关键字段说明 ​

字段必填说明
id是模型唯一标识符
name否显示名称
vendor否模型供应商
apiKey是API 密钥，支持 ${环境变量名} 语法
url是API 端点，必须以 /chat/completions 结尾
maxInputTokens否最大输入 Token 数
maxOutputTokens否最大输出 Token 数
supportsToolCall否是否支持工具调用
supportsImages否是否支持图片输入
supportsReasoning否是否支持推理模式
relatedModels否关联模型配置

5.4 配置热重载 ​

  • 配置文件修改后支持热重载
  • 1 秒防抖延迟
  • 无需重启应用

六、最佳实践 ​

6.1 安全建议 ​

  • 使用环境变量存储 API 密钥，避免明文存储
  • 不要在提示词中包含敏感信息
  • 审查生成的代码，避免引入安全漏洞

6.2 提示词技巧 ​

明确具体的需求

bash
# 不推荐
codebuddy "写个函数"

# 推荐
codebuddy "写一个 TypeScript 函数，输入一个字符串数组，返回去重后按字母排序的结果，使用 Set 和 Array.sort"

6.3 工作流程建议 ​

  1. 先理解后修改：让 AI 先解释代码逻辑，再提出修改建议
  2. 小步迭代：将大任务拆分为多个小任务逐步完成
  3. 验证输出：生成代码后及时运行测试验证
  4. 版本控制：重要修改前先提交当前代码

七、常见问题 ​

7.1 配置后模型未出现 ​

问题：配置了 models.json 但模型未出现在下拉菜单中

解决：

  1. 检查 JSON 语法是否正确
  2. 确认配置文件路径正确
  3. 如果配置了 availableModels 字段，确保模型 ID 已包含在内
  4. 等待 1 秒热重载完成

7.2 API 密钥相关 ​

问题：提示 "API key not found" 或 "Unauthorized"

解决：

bash
# 检查环境变量
echo $MIMO_API_KEY

# 重新设置
export MIMO_API_KEY="your-api-key"
